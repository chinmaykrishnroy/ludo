# Ludo Club v0.1.5

Human turns now allow **15 seconds to roll** and **30 seconds to choose a token**.
The shared rule engine assigns these deadlines for both online and offline play,
including bonus rolls and skipped turns. Online enforcement remains on the
server: refreshing does not renew a deadline. Existing saved absolute deadlines
are retained until the next phase begins.

This release includes all v0.1.3 voice finalization, transport protection,
browser-storage recovery and offline-save validation changes. Voice recording
limits remain **60 seconds and 1 MiB**.

Validation covers deterministic phase durations, automatic backend roll/move
expiry, first-legal fallback and persisted reconnects. The full release pipeline
also checks unit/integration tests, Chromium/Firefox/WebKit behavior and both
AMD64/ARM64 image smoke tests before publication. The Linux WebKit build lacks
MediaRecorder; it verifies the unsupported fallback, while Chromium and Firefox
exercise actual codec recording/upload/replay/cancellation using generated audio.

Physical Android/iOS microphone confirmation and the remaining operational work
in [TODO.md](../TODO.md) remain separate acceptance gates. See [v0.1.3](v0.1.3.md)
for the preceding fixes and known hosting limitations.

The earlier v0.1.4 tag points to a package-version mismatch and produced no supported release image; this version preserves that tag and packages the combined changes with matching metadata.
