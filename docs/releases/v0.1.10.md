# Ludo Club v0.1.10

Token movement now plays once. The dice presentation previously sent an older
board revision back to the token renderer during the next player's roll. That
restarted the preceding movement path, creating a visible snapback despite a
correct game state. The board now always follows the latest authoritative
snapshot; only the die's actor and timer stay held through the reveal.

Tokens animate actual position changes. Restoring a saved game does not replay
its historical last move, and completed movement paths are reduced to their final
position so later updates cannot restart them.

The die now has six fixed, solid faces. It tumbles continuously while waiting,
rotates from its current pose onto the authoritative result, and settles before
the result hold and turn handoff. Pips are never shuffled or repainted during the
roll. Reduced-motion mode reveals the same result without tumbling.

Regression coverage includes the reproduced multiplayer revision rollback,
subsequent rolls and snapshots, saved-game baselines, every die face, slow
responses and reduced motion. Dice generation, game rules, server deadlines and
saved-game formats retain their existing authoritative behavior.
