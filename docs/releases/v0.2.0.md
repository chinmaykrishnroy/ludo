# Ludo Club v0.2.0

Major milestone release bringing a complete visual and architectural overhaul, responsive mobile thumb accessibility, modularized domain components, and cross-device perfection:

- **Pro Studio Visual Architecture**: Brand-new dark & light design system with multi-hue dynamic aurora backlight glows, interactive 3D stadium board showcase with mouse/touch perspective tilt, kinetic ambient particles, and bouncy live turn indicators.
- **Mobile Thumb Accessibility**: Re-architected mobile layout placing primary CTAs ("PLAY WITH FRIENDS" and "PLAY OFFLINE") directly within comfortable one-handed thumb reach, with sticky anchored actions in the lobby and play screen.
- **Physical Drag-and-Drop Lobby**: Real-time seat swapping powered by pointer events with vertical snapping physics, replacing legacy up/down arrow buttons.
- **Granular Bot Difficulty Levels**: Per-seat bot AI tuning from level 0 (first legal move) to level 10 (expert Monte Carlo Tree Search) with compact inline level selectors.
- **Color-Coded Chat & Dynamic Mentions**: Table chat bubbles now render in each player's token color with high-contrast text for both dark and light modes; tagged player names render in dedicated color pills. Upgraded the chat input row to sleek glass styling with rounded attachment controls.
- **Full Codebase Modularization**: Refactored monolithic files (6,000+ lines) into focused, domain-driven modules:
  - `src/features/modals/`: Isolated dialog components (`SettingsDialog`, `RulesDialog`, `OfflineDialog`, `GameMenuDialog`, `VictoryDialog`, `ModerationDialog`, `InstallDialog`, `LeaveResetDialog`).
  - `src/features/lobby/`: Dedicated lobby domain (`RoomLobby`, `RoomBrowser`, `BotDifficulty`, `useRoomSession`).
  - `src/features/game/`: Extracted offline game controller (`useOfflineGame`) and board rendering logic.
  - `src/features/chat/`: Focused chat components (`RoomChat`, `RoomTools`, `MessageText`, `ChatPreviews`).
  - `src/styles/`: Split monolithic CSS into 8 domain stylesheets (`variables.css`, `base.css`, `dialogs.css`, `lobby.css`, `board.css`, `chat.css`, `effects.css`, `home.css`) with all dead and duplicate rules purged.
- **Cross-Device Inspection & QA**: Exhaustively verified across iPhone 14, Google Pixel 7, and Desktop 1440x900 viewports with zero horizontal overflow, zero layout clipping, and zero truncation.
- **Offline & PWA Enhancements**: Hashed content precaching in `sw.js` for instant offline loading and seamless home-screen installation.
