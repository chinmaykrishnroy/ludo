# Ludo Club v0.1.20

- Bye emoji reaction: Replaced the wave reaction (`👋`) with the smirk emoji (`😏`) labeled "Bye" for quick player reactions and bot farewell interactions.
- Enhanced reaction animations: Substantially enlarged reaction emoji scale with dynamic spring, pop, float sway, confetti explosion, and multi-ring shockwaves, keeping them semi-transparent with glowing drop-shadows so the board remains clearly visible.
- Semi-transparent soundboard: Upgraded the soundboard modal, category selector, and clip list with translucent frosted-glass styling (`backdrop-filter`) matching the message overlay aesthetic so underlying gameplay is not blocked.
