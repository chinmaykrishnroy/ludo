# Ludo Club v0.1.14

Ludo Club v0.1.14 delivers comprehensive reliability, fault-tolerance, and
latency improvements for the WebSocket live push-to-talk voice system.

## Resilient Live Push-to-Talk Audio

- **Fault-Tolerant Floor Granting**:
  - Removed the rigid 100% all-listeners readiness gate. In multi-player rooms,
    live talk now proceeds as long as available listeners are reachable,
    dropping problematic or unready connections individually without aborting
    the transmission for everyone else.
  - Enabled live talk in solo and bot rooms without crashing or rejecting the floor.
  - Preserved bidirectional block enforcement without treating blocked players
    as solo sessions.

- **Background Tab Audio Playback**:
  - Tab visibility changes no longer mute or suspend incoming live audio playback.
    Active Web Audio output continues smoothly in the background, providing a
    seamless Discord-like experience.

- **Universal Hardware & Sample Rate Support**:
  - Eliminated the strict 48,000 Hz hardware audio constraint. Web Audio
    natively resamples decoded Opus frames to the system hardware rate, enabling
    live voice across AirPods, Bluetooth headsets, and mobile Safari (44.1 kHz).

- **WAN Latency & Jitter Resilience**:
  - Increased TCP socket headroom (`LIVE_BUFFER_BYTES`) from 1 KB to 16 KB,
    preventing spurious connection drops during normal packet bursts.
  - Extended floor grant timeout to 3,000 ms and delivery finalizer timeout to
    3,500 ms to eliminate false voice note fallbacks over public internet routes.

- **Mobile Audio Activation**:
  - Added `touchstart` capture and immediate unlock invocation on room entry,
    ensuring mobile browsers (iOS Safari and Android Chrome) immediately unlock
    audio playback on initial interaction.
