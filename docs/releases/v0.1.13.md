# Ludo Club v0.1.13

Ludo Club v0.1.13 introduces a modular, domain-driven architecture, robust
server-side game action idempotency, structured telemetry, accessibility
enhancements, and expanded test coverage across the entire system.

## Domain-Driven Architecture

- Frontend concerns are decoupled into domain feature modules:
  - `src/features/game`: Board, Dice, PlayScreen, offline AI, and feedback.
  - `src/features/chat`: RoomChat dialog and chat controller.
  - `src/features/voice`: VoicePanel, useRoomVoice, Opus worker codecs, and live streaming.
  - `src/features/lobby`: RoomBrowser and BotDifficulty selectors.
  - `src/store`: State persistence, local appearance, server admission, and user profile.
  - `src/lib`: Common dialog focus containment, error reporting, number formatting, and photo preparation.
- Server architecture is separated into dedicated domain modules:
  - `server/rooms`: Room registry, member channels, room view projection, and host authority.
  - `server/game`: Game action authority validation, turn deadlines, and action idempotency.
  - `server/voice`: Live voice relay orchestration.
  - `server/metrics`: Structured JSON logging, GameTelemetry metrics, and health telemetry.
- 100% backward-compatible re-exports are maintained at root paths so existing imports and tests remain seamless.

## Server Authority & Action Idempotency

- Added `validateGameAction` to enforce deterministic turn order, revision state, phase legality, and human vs. bot control.
- Added `IdempotencyCache` for `game:roll` and `game:move`, deduplicating replayed socket actions across network retries, double-clicks, and reconnection bursts.
- Canonical state models and runtime Zod event validation schemas are consolidated in `shared/types/`.

## Observability & Telemetry

- Structured JSON logging (`logInfo`, `logWarn`, `logError`) outputs standardized diagnostic logs.
- Added `GameTelemetry` tracking active room counts, games started/finished, dice rolls, token moves, and disconnect/reconnect rates.

## Accessibility & Performance

- Added `@media (prefers-contrast: more)` styles for high-contrast accessibility across boards, badges, dialogs, and tokens.
- Memoized high-frequency components (`Token`, `Board`, `BotDifficulty`, `RoomBrowser`) eliminating unnecessary re-renders.
- Aligned ARIA attributes and live region announcements.

## Quality & Verification

- Test coverage expanded to 138 unit and integration tests (`tests/game-rules-edge.test.ts`), verifying idempotency caching, authority rules, Crockford room code entropy, and game rule edge cases.
- Full Playwright E2E test suites verified across Chromium, Firefox, and WebKit.
- ESLint 10 flat configuration and Git pre-commit hooks via Husky + `lint-staged`.
- Pull request template (`.github/PULL_REQUEST_TEMPLATE.md`) with domain checklist.
